Featured Project

SEO AI &
Analytics Platform

I built an internal SEO workflow system that turns scattered search data into clear priorities, AI-supported recommendations, and trackable execution.

React Node.js OpenAI API Google Analytics Search Console WordPress API Supabase

The Problem

SEO data existed, but decisions were still manual.

Before

Scattered workflow

  • Search Console data was reviewed manually
  • Opportunities were tracked in separate places
  • Priority was based on judgment, not a system
  • Repeated recommendations were easy to create
After

Operational SEO system

  • Search signals are translated into tasks
  • AI helps diagnose what should change
  • Actions are ranked by impact and effort
  • Execution and measurement stay connected

Why I Built It

The goal was not to create another dashboard. It was to reduce decision fatigue.

I wanted the system to answer the question that matters most:
"What should we work on next, and why?"

Thought Process

How I decided what the system should surface.

Search volume alone is not enough. The platform looks for signals that suggest a real opportunity.

01

Demand

Detect keywords and pages already receiving search visibility and impressions.

02

Weakness

Identify weak CTR, low rankings, or content gaps affecting performance.

03

Intent

Understand whether the query signals informational, local, or transactional intent.

04

Action

Recommend the best next step, from page optimization to content generation.

Workflow

The product follows how SEO work actually happens.

1

Collect

Bring in Search Console and analytics data.

2

Analyze

Detect gaps, intent, weakness, and priority.

3

Decide

Generate the best next action with context.

4

Execute

Publish, mark implemented, and measure impact.

Key Screens

Only the screens that tell the story.

Design Decisions

What I intentionally added, reduced, and protected.

Added

  • Impact, effort, and confidence signals
  • Task status and implementation tracking
  • AI-generated diagnosis and next steps
  • Clear separation between analysis and execution

Reduced

  • Raw SEO data without context
  • Manual spreadsheet-style decision making
  • Repeated recommendations
  • Too much SEO jargon in the UI

Protected

  • Human review before publishing
  • Traceability from task to evidence
  • Simple language for business users
  • A calm interface despite dense data

Technical Focus

Built around workflow, not just tools.

API orchestration between GSC, GA4, OpenAI, and WordPress.
Duplicate prevention for AI-generated recommendations.
Priority logic based on impact, effort, confidence, and search signals.
Reusable task structure for content, local pages, and page improvements.

This project reflects how I approach systems: understand the workflow, reduce friction, surface decisions, and make execution easier.
